# Glossary

| Term | Definition |
|------|------------|
| Agent | A system that can perceive input, reason, decide, and act (possibly using tools) toward a goal. |
| Context Window | Maximum token span the model can attend to in a single request. |
| Tool Invocation | Structured call where model output triggers execution of an external function/service. |
| Reflection Loop | Pattern where model critiques or revises its own prior output. |
| Planning | Decomposition of a complex goal into steps. |
| Chain-of-Thought | Explicit reasoning tokens preceding a final answer. |
| Retrieval Augmentation | Injecting external factual context into prompt. |
| Hallucination | Confident but ungrounded / false response. |
| Guardrail | Mechanism to constrain or validate model outputs before use. |
| Memory (Short-term) | Ephemeral context inside prompt for current interaction. |
| Memory (Long-term) | Persisted knowledge across sessions. |
| Evaluation Set | Curated dataset used to score output quality or correctness. |
| Autonomy | Degree to which an agent self-directs without human intervention. |
| Instrumentation | Capturing metrics/logs/traces for observability. |
| Safety Filter | Post-processing step removing sensitive or disallowed output. |
