# 12-Week Agentic AI Program Overview

A guided progression from prompt craftsmanship to fully evaluated, observable, and governed agentic systems.

| Week | Theme | Core Skill | Key Deliverable |
|------|-------|-----------|-----------------|
| 1 | Prompt Engineering | Instruction & pattern design | Prompt playbook + lab outputs |
| 2 | Context Engineering | Retrieval & grounding | Context assembly pipeline |
| 3 | MCP Intro | Tool/server protocol | Minimal MCP tool integration |
| 4 | Agent Experience | UX loops, guardrails | Agent interaction flow map |
| 5 | Role & Skill Definition | Capability modeling | Role & skill spec library |
| 6 | Reasoning & Planning | Decomposition strategies | Reasoning trace + evaluator |
| 7 | Autonomy & Control | Loop design & safety stops | Autonomous loop prototype |
| 8 | DevOps for Agents | Packaging & deployment | Deployment checklist |
| 9 | Observability & Monitoring | Metrics & tracing | Log + metrics dashboard sketch |
| 10 | Project Kickoff | Scoping & backlog | Project charter |
| 11 | Build & Integrate | Implementation & iteration | Functional demo alpha |
| 12 | Demo Day | Storytelling & polish | Final presentation + repo |

## Learning Pillars
1. Precision prompting → structured reasoning
2. Context curation → factual grounding
3. Tool orchestration → capability extension
4. Evaluation loops → improvement engine
5. Observability → trust & accountability
6. Governance & safety → responsible deployment

## Participant Success Pattern
Draft → Evaluate → Refine → Automate → Instrument → Govern

## Suggested Weekly Workflow
1. Read week overview & goals
2. Clone/update environment
3. Run starter lab
4. Add experiments (log prompts, outcomes)
5. Evaluate vs golden set
6. Improve prompts / retrieval / reasoning steps
7. Document learnings in `reflections.md`
8. Commit & push artifacts

## Rubric Dimensions (Global)
- Clarity & structure of prompts/tool specs
- Reproducibility (environment + scripts)
- Evaluation rigor (metrics + analysis)
- Observability / cost awareness
- Safety / governance considerations
- Iterative improvement evidence

## Time Management Guidance
| Activity | % Weekly Time |
|----------|---------------|
| Reading / Orientation | 10% |
| Hands-on Lab | 35% |
| Experimentation | 25% |
| Evaluation & Instrumentation | 15% |
| Reflection & Documentation | 10% |
| Stretch Goals | 5% |

Stay focused on incremental iteration over perfection. 🚀
